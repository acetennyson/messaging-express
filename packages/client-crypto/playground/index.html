Each device has an X25519 key pair. The public key is what gets registered with the server; the private key never leaves the device.

4. Backup and recovery

Alice's private key is encrypted under a key derived from her passphrase with Argon2id. The server stores the blob and the parameters, and cannot read it. The demo uses small parameters so it is quick; the real default is 19 MiB, 2 passes.

5. Key store (IndexedDB in this browser)

Where a real device keeps its private key and conversation keys. Unlike everything above, this survives a reload: save, reload the page, list. Keys are namespaced per server and per account, so two accounts on one browser never see each other's keys.
